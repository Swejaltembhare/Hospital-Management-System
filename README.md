# 🏥 MediCare - Hospital Management System

A simple and modern full-stack web application built to manage hospital operations, doctor appointments, and patient records efficiently.

---

## ✨ Features

* **Admin Dashboard**: Manage doctors, patients, appointments, and view real-time statistics.
* **Doctor Portal**: View daily patient schedules, update availability, and check medical histories.
* **Patient Portal**: Book appointments instantly, track schedule status, and view prescriptions.

---

## 🛠️ Tech Stack

* **Frontend**: React, Vite, Tailwind CSS, Lucide-React, Framer Motion
* **Backend**: Node.js, Express.js, MongoDB
* **API Communication**: Axios with JWT Authentication
